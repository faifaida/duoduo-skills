# Oday 横屏对谈复刻配方

用于“多多左、人物右”的横屏对谈。目标是让观众先认识这个人，再理解他如何在这里生活；不是把一场采访压成问答摘要。

## 素材准备

1. 取原始双人同框采访；先完整转录，不用自动字幕直接上片。
2. 先为这一期写一个主题问题；同一人物可有多期，各期按主题选料，不按采访时间顺序切上、下集。
3. 按问题拆段，而不是按回答拆段。连续问出的两个问题也分别编号。
4. 选 3–5 个真正有叙事作用的回答：来处、具体选择、冲突/转折、此刻在这里的原因、一个真实收尾。
5. 建立音频优先的纸上时间线：`问题卡 → 完整问题 → 回答 → 问题卡 → 完整问题`。问题不能被删掉。

## 画面与声音

- 输出 1920×1080、30 fps、H.264、无黑边。
- 画面保持双人全景；多多左、人物右。活动说话者可轻微提亮，另一侧轻微收饱和，但两边都保留，尤其保留提问者反应。
- 对谈的环境音可以在句间存在；无效气口/等候才切。不要让语速变快，也不要用强降噪把人声压闷。
- 安全的人声处理起点：high-pass 80 Hz、轻度自适应降噪（从低强度开始）、约 1.5:1 压缩、响度标准化。每一步和原声 A/B 对听；一旦出现金属感、泵动、白噪声或闷，撤回。
- 做暖 Fuji / Classic Chrome 倾向时，只微调高光、对比、肤色和综合色温；不把绿植压成脏黄，也不把白衣染色。

## 字幕

- 英文原句在第一行、中文在第二行。译文忠实、简短，不替人物提升立意。
- 多多问题：左上；人物回答：右上。字幕应位于头顶上方且不压脸。
- 粗体宋体感，31 px、字重 800，亮蓝绿 `#35EDFF`；在浅色或绿植背景上使用 1 px、85% 不透明度细黑描边。不要黑底、粗黑边或重阴影。
- 修改剪辑时长后，重校对其后所有字幕。最后逐句播放，尤其检查多多左侧的每个问题。

## 问题概念卡

每一个新问题都遵循同一个低自由度模板：

1. 取该问题开始前的真实画面，选一帧并冻结 1.4–1.8 秒。
2. 将该段对谈人声静音；只铺极轻的短打字声。
3. 屏幕中间以中文摘要逐字出现，问题结束前保持完整一句。
4. 卡结束时硬切回同一冻结时刻后的真实问题，不可在说话嘴形上先出现卡。

例如：`为什么来到斯里兰卡？`、`他会讲自己的故事吗？`、`他会接待以色列客人吗？`、`他们会聊天吗？`。`HUMMUS` 与 `在这里，展示这里` 可以作为真实回答支撑下的主题高潮卡。

## 结尾与验证

在最后一句回答之后，至少留一个真实结束动作：两人笑、起身、收设备、道别或离开。让环境声自然延续，再短淡出。

不要把整个长原片在每一次输出中重复解码。只对选择段和新增尾段渲染；合成前检查每一段都有正常容器 metadata。最终 master 必须通过 `ffprobe`，并抽看：开头、每一问题卡、每一问题字幕、主题卡、最后 10 秒。
