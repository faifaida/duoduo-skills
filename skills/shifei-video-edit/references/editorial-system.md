# 世斐编辑系统

## 北极星

世斐不是旅行攻略号，也不是异域景观号。它记录一个人走进真实世界后，如何因人物、地点、权力、自由成本和现实规则而改变理解。每条片至少含：**冲突开头 → 具体现场 → 转折 → 当时观点与现在回看的二次理解 → 人物答案或开放动作。**

人物与事件优先于抽象旁白。真实证据优先于“很有道理”的解释。

## 片型路由

| 片型 | 目标 | 常用时长 | 画幅 |
|---|---|---:|---|
| People | 通过一个具体的人理解这里 | 2:00–3:30 | 默认 9:16；明确要求时 16:9 对谈 |
| Field Notes | 多多某天在现场发生的理解 | 60–180s | 9:16 |
| 旅行蒙太奇 / 观点 | 旁白或对镜与可验证现场互证 | 60–150s | 9:16 |
| 攻略信息 | 地点、费用、路线与避坑 | 按信息密度 | 9:16 |

## 画面证据排序

1. 正在说话的人和另一人的反应。
2. 被说到的真实动作、工作、物件或现场。
3. 同一地点的环境与可见细节。
4. 同一天/同一段经历的补充画面。
5. 经授权或生成的补充素材，只能补明确且不冒充现场的内容。

不要每一句都切 B-roll；回答足够强时，连续 15–25 秒坐着说话是正确的。不要用海浪、日落、街景把人从自己的故事里盖掉。

## 素材边界

- `SHIFEI_HERO`：采访关键回答、人物沉默/笑/哭、争论、告别、连接、事件现场、重要原声。
- `WEAR_HERO`：泳衣、身体、版型、产品测试、专门拍的品牌主镜头。除非它本身证明一个人物/事件，否则不做世斐主镜头。
- `SHARED_WORLD`：海、街、食物、青旅、骑车、日落、普通生活碎片；共用时换裁切、起止点、声音和叙事任务。

## 事实门

只把原始视频、原始录音、原始 Journal、明确的当事人确认当事实。人物姓名、地点、日期、身份、战争、民族、边境、医疗、法律、药物、爱情路径若不确定，不能以 AI 常识补全。把不确定项写进 CUT_NOTES。

## 每支片的强制生产闸门

任何世斐片一律按以下顺序推进，不能跳关：

1. **审原片与事实**：先看原始视频、原声、日志和现场动作；自动转写只能用于找素材，逐字台词和事实归属必须回到原片人工确认。
2. **文字锁定**：先和多多确认观众最终会听到的文字。文字稿必须标出`【保留原片】`、`【现场声】`、`【新增旁白】`；现场已有对镜/原声优先，不得用一篇新录的完整旁白覆盖它。此阶段不交 storyboard，不用时间码表冒充故事已经成立。
3. **Storyboard / 分镜锁定**：文字确认后，逐镜写明原文件与原时间码、时长、画面截图、实际说话文字及字幕、匹配关系、ID/章节卡、剪辑方法、转场、环境声/BGM/SFX、动效和新增口播落点。没有原片核验的画面或台词不得写成已确认。
4. **剪辑**：只按已锁定 storyboard 剪。若素材、时长或事实使故事不成立，退回文字或 storyboard 阶段重定，不能靠音乐、混剪、字幕或特效把它伪装成成片。

“先剪一个感觉出来再补故事”不适用于世斐。现场事件的情绪与判断必须由声音、人物动作和具体关系先成立。

## 写稿硬规则：长度、目的与爆款结构

### 先锁长度

除非多多明确指定其他时长，世斐竖屏叙事片的默认交付时长固定为**成片 1:50–2:10（按多多口播 1.2× 播放）**。先按这个时长写完整的“观众最终会听到的文字”，不能交 60–90 秒短纲后把它称作成稿，也不能为凑时长再用风景、音乐或空话填满。People / 横屏对谈及用户另行指定的片型，先在 Brief 里锁定各自时长。

### 每次动笔前必须完成的 Script Brief

写任何世斐脚本前，先核对以下五件事；用户只要文字稿时，可以内部完成，不用把研究报告塞给用户，但绝不能跳过：

1. **这条的目的**：它要给陌生人一个关注理由、让已有观众更认识多多，还是承接一条明确的内容线？这条片为什么值得占用两分钟？
2. **观众的追看缺口**：开头必须给出一个可见的冲突、反差、资格不足或奇怪动作，让人想追问“接下来怎么办 / 她凭什么 / 这个人到底在干嘛”；不能只报地点、心情或主题。
3. **真实证据**：哪几段原话、人物反应、动作、物件和环境声能证明每一个关键判断？原片不足时先缩小命题，不许用漂亮 B-roll 代替证据。
4. **对标的可迁移结构**：每次从已实际看过的高赞同类片中选一个结构发动机（如`资格不够，事情已经发生`、`一个违和动作逐渐变复杂`、`先报结果，迅速交代代价`），只借发动机，不照抄标题、语气、金句或剪法。标题卡片和想象出来的影片内容不能当对标。
5. **世斐自己的深度**：多多在事件里做了什么、误判了什么、又付了什么代价？必须让她也在关系里，不能站在外面讲“当地”“动物”“他人”或“旅行”的正确答案。

### 两分钟片的优先结构

默认使用一条持续推进的故事线，而不是“地点流水账”或“观点合集”：

```text
开头：一个可见的异常 / 风险 / 反差
→ 现场：事情真的怎样发生
→ 撞坏：新事实使最初判断变复杂
→ 卷入：多多自己的钱、身体、选择或尴尬也在其中
→ 收尾：留在一个仍在发生的动作、原声或未被替观众讲完的问题
```

脚本要让人因**未完成的问题**继续看，不靠连续海报金句；认知只在事件走完后出现一次。对社会关系、旅行、人物和动物的片，尤其避免开场就抛“旅行的意义”“如何尊重当地”“生态困境”等大题。

## 通用视觉与声音

- 真实感大于电影感；保留风、汗、湿头发、桌面杂物、轻微手持、曝光变化。
- 竖屏常规版本保留地点本色、不统一套 LUT；人物对谈可以按明确 brief 做克制暖 Fuji 感。
- 硬切优先；不用无意义 whoosh、过度速度渐变、电影黑边或插件转场。
- 音频层级：现场/对谈 > 多多旁白 > 环境 > BGM > 点缀 SFX。BGM 永远不可盖住前三级。
- 亮蓝绿 `#00B6C5` / `#1FCEDD` 只作强调；不要铺满背景。对谈指定用 `#1FCEDD`。
