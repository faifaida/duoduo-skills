# Sri Lanka Field Notes

Field Notes 是多多的每日现场理解，不是旅行 Vlog。固定片头可用：`SRI LANKA FIELD NOTES`，下一行 `DAY X / SUBJECT`；无需 logo 动画。

优先顺序：当天原始 Journal / 原声 → 当天真实照片与视频 → 事后对镜补充。3/16 之类原始 Journal 无正文的日期不凭空生产。

剪辑时保留事件前后顺序，避免把不同日期伪装为同一天。旁白要能被画面或记录证实：说到一个人，就让人或其动作出现；说到地点，让场景给出具体证据；说到感受，可以留多多的停顿和身体状态。

## 现场原声优先

Field Notes 的声音骨架优先级是：**事发当下的对镜/对话/环境声 → 事后但仍在现场的对镜 → 极少量新增旁白**。已有现场对镜哪怕表达粗糙、重复、英语不完整，也先保留其中能推进故事的句子、表情、停顿和自我修正；新增旁白只负责跨过原片没有说清的连接，不能复述、更不能盖住现场。

写文字时先给“听到的版本”，而不是先给一篇完整后期口播：

- `【保留原片】`：原话的经人工核验字幕；
- `【现场声】`：浪、人群、摊贩、脚步、沉默等可证明空间的声音；
- `【新增旁白】`：仅保留必要的1–2段，写清它解决哪一个原片无法解决的问题。

一个有社会关系的旅行现场，先让一个可见的奇怪动作把人拉进来，再让事实把原判断弄复杂：人物做了什么、他/她为什么可能这样做、多多自己的钱/身体/位置怎样也卷了进去。不要把它剪成“如何尊重当地”“旅行的意义”一类结论片。

人物、动物、环境与游客之间的类比，必须由相邻且可见的动作推出，不能把某个国家或“本地人”概括成标签。生态、收入、行为后果等外部事实，只有在原片、原始记录或可靠来源支持时才说；无法确认时归为当事人的原话或多多当下的感受。

结尾优先留在一个尚在发生的动作或环境声上：海浪、等待、走远、没有被回答的眼神。不要替观众总结正确答案，也不要用旁白把道德困境讲完。

字幕以英文原句 + 简洁中文为主；一条最多 2–3 个全屏大字强调。BGM 低于现场与旁白，情绪峰值允许降 BGM、留 0.5–2 秒环境声或呼吸。
