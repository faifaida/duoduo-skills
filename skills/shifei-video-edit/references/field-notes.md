# Sri Lanka Field Notes

Field Notes 是多多的每日现场理解，不是旅行 Vlog。固定片头可用：`SRI LANKA FIELD NOTES`，下一行 `DAY X / SUBJECT`；无需 logo 动画。

优先顺序：当天原始 Journal / 原声 → 当天真实照片与视频 → 事后对镜补充。3/16 之类原始 Journal 无正文的日期不凭空生产。

剪辑时保留事件前后顺序，避免把不同日期伪装为同一天。旁白要能被画面或记录证实：说到一个人，就让人或其动作出现；说到地点，让场景给出具体证据；说到感受，可以留多多的停顿和身体状态。

字幕以英文原句 + 简洁中文为主；一条最多 2–3 个全屏大字强调。BGM 低于现场与旁白，情绪峰值允许降 BGM、留 0.5–2 秒环境声或呼吸。
