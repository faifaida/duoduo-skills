# 生产与验收

## 开剪前

- [ ] 已确认这是世斐，不是多多 OS 或 DUODUO WEAR。
- [ ] 已确认人物、地点、日期、语言与素材来源。
- [ ] 已完成全转录和风险标记。
- [ ] 已有可单独成立的声音结构与每段剪辑理由。
- [ ] B-roll / 生成素材有明确证据任务与授权来源。

## 精剪中

- [ ] 所有多多问题都在回答前出现；提问者字幕没有遗漏。
- [ ] 每次裁掉停顿后，字幕、嘴形和音频仍同步。
- [ ] 概念卡是冻结帧 + 静音 + 逐字 + 轻 SFX，绝不在运动嘴形上盖卡。
- [ ] 人声自然，背景噪声被控制但不闷、不泵、不假。
- [ ] 颜色服务真实地点和肤色；无黑边、无重 LUT、无无意义转场。

## 输出前

- [ ] 用 `ffprobe` 确认 MASTER 有正常时长、音轨和可读容器；中断文件不可交付。
- [ ] 抽看开头、每个问题、每张概念卡、每一次转折和最后 10 秒。
- [ ] 对照转录逐句复核双语字幕；尤其复核多多左侧提问。
- [ ] 在明亮、白色和绿植背景抽看字幕：亮蓝色保留，字重至少 800；如读不清，已使用 1 px 细黑描边而非黑底。
- [ ] 若人物有多期，已验证本期有独立主题和不重复的证据链，不是按采访时间硬切的上、下集。
- [ ] 结尾有真实收束，不是回答后突然黑场。
- [ ] 输出 MASTER、SRT/ASS、CUT_NOTES、USED_ASSETS、UNUSED_GEMS。

## 世斐竖屏硬指标复核（精确数值见 `production-spec.md`）

- [ ] 逐镜核算：人 ≥ 80%、多多本人 ≥ 60%、landscape ≤ 20%、图片 : 视频 = 3 : 7（按镜头数）。
- [ ] 画面去重复跑：任意两段同时满足「感知哈希汉明 < 10 且 直方图相交 > 0.85」才判为近重复（同款构图但颜色不同不算重复）；跨文件生效。
- [ ] 成片时长落在 1:50 – 2:30，且对镜 / 原声主干为 1.2×。
- [ ] 开口 1–2s 为现场声；BGM 全程低于人声（隔离轨验证）；退音乐段 RMS = 0。
- [ ] 字幕：亮蓝 / Bold / 暗边、≤ 10 字 / 屏、不遮嘴 / 动物 / 关键信息、浅背景（海水白沙）可读。
- [ ] 转场全为硬切或 ≤ 6 帧叠化；无 whoosh / 擦除 / 滤镜秀。
- [ ] 联系表标注各段占比、退音乐段、重点字卡落点。
