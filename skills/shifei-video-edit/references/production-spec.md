# 世斐视频制作硬指标（素材 / 剪辑 / 声音 / 字幕 / 转场）

> **适用范围**：世斐竖屏叙事片、认知旅行、Field Notes 旁白 + B-roll 型。
> People / 横屏对谈遵循 `people-interview.md` 与 `oday-horizontal-recipe.md` 的专属规范，但其「人/多多/风景配比、不类似画面、原声优先、不 AI 模仿、硬切为主」同样适用。
>
> **本文件是数值与结构的唯一权威来源。** `editorial-system.md`、`subtitle-bgm-remix.md`、`production-qa.md` 与本文件冲突时，**以本文件为准**。

---

## A. 素材配比硬指标（逐镜双维度核算）

每条成片按「镜头数」与「时长」两个维度核算，交付前在 CUT_NOTES / 联系表标注实际占比：

- **人（people）≥ 80%**：画面里要有正在发生关系 / 动作的真实人物。纯风景、纯物件、纯文字卡不计为人。
- **多多本人（DUODUO）≥ 60%**：多多出镜（对镜、现场被拍、真实反应）的镜头时长占比。可由「对镜 + 现场被拍 + 反应」累加；纯旁白 B-roll 不计入多多本人。
- **landscape（风景）≤ 20%**：空镜、海、街、天空、日落等无人或人极小的镜头。这是**上限不是目标**——能用人就不用风景。
- **图片 : 视频 = 3 : 7**（按镜头数）：静态照片最多占 30%，动态视频至少 70%。照片用于补无法拍到的现场或定格强调，不替代视频证据。
- **时长目标 1:50 – 2:30**（成片，按多多口播 **1.2×** 播放后计）。Field Notes / 蒙太奇若用户另有指定，从其指定。
- **不用重复或类似画面**：任何两段镜头不得内容重复或观感相似。
  - 选源阶段做**画面去重**：每候选抽「竖屏裁切后」帧算 感知哈希(8×8) + 色彩直方图；
    - **近重复判定（双闸同时满足）**：汉明距离 < 10 **且** 直方图相交 > 0.85 视为重复/类似，禁止同时使用；跨文件同样生效。
    - 若仅汉明 < 10 但直方图相交极低（例如同款居中构图但颜色完全不同），只说明「构图模板相同」，不算素材重复，保留并标注待人工复核。
  - 去重哈希必须复刻成片烘焙的 720×1280 竖屏中心裁切，使源级去重对齐成片观感（否则源级去重与成片观感会脱节）。
  - 同一地理 / 同一动作的镜头若只能换裁切无法换内容，视为类似，需替换为不同证据或诚实留白。

## B. 对镜 / 原声主干 1.2× + 剪 filler 规则

- 多多对镜、原声主干（说话、反应、现场声）**加速至 1.2×** 播放，作为默认节奏基准。
- **剪掉**：明显重复的句子、假启动（开口又重来）、超过约 **0.8s** 的空等（长时间静默、无信息停顿）。
- **保留**：人的呼吸、迟疑、笑、环境声、情绪停顿——这些是真实感，不是 filler。
- **不要机械当 filler 删**：「其实、然后、就是、那个」等口语连接词若承载节奏或思考痕迹，**保留**；只有当它们纯粹重复且无信息时再剪。判断标准是「删掉是否丢失人的真实感」，不是字面匹配。

---

## C. 原声优先 / 新增旁白只填空 / 不 AI 模仿

- **所有能用的现场声优先**：原片对镜、现场原声、环境声是第一层；新增旁白只在空缺处补，不覆盖已有声音。
- **绝不让新增旁白盖住画面中张嘴的原片对镜**：凡原片人物在说话（嘴在动、有同期声），该段以原声为主，新增旁白不得压在上面；只能在原声结束后的空隙补。
- **不要用 AI 模仿多多声音**：任何新增旁白必须由多多真人录制（用户提供的 .m4a）；禁止 TTS / 声码器 / 克隆多多声线。
- **全片叙述必须从可见动作出发**：每个判断 / 认知都必须有画面里可见的人物动作、现场或物件顶住；禁止纯旁白空讲。
- **保留用户已锁文字的情绪和困境**：定稿正文不可改写；剪辑只做节奏与画面匹配，不净化口语、不补升华、不替观众讲完。

## D. 字幕细则（竖屏，与世斐旧片一致）

- 字体 STHeiti Medium；竖屏 720×1280 下 46px（1080×1920 同比放大）；颜色亮蓝 `#1FCEDD`（ASS `&H00DDCE1F`）；**Bold = 1**；低对比暗边 `OutlineColour=&H66000000, Outline=2` + 轻阴影 `BackColour=&H55000000, Shadow=1`。
- **可读性优先**：在海水、白沙、亮天空、白墙等浅色背景上必须清晰——靠暗边 + 阴影保证，不靠黑底块。
- **安全边距**：竖屏底部偏上，左右各留 ≥ 40px；不贴边、不出血。
- **不遮挡**：绝不让字幕盖住动物、人物的嘴、以及画面关键信息（脸、手、字、标识）。必要时下移或缩短该屏。
- **每屏 ≤ 10 个汉字**，按词组边界断句，绝不拆词；单词（人名 / 地名）可单独成屏。
- **只用少数重点字卡**：全片只额外突出 1–3 个真正重要的词 / 句（如 majority / minority、priming / stereotype），不铺满金句卡；重点字卡不替代口播。

---

## E. 音乐（无歌词 / 克制 / 略欢快）

- 选材：**无歌词**；**克制**（peak ≤ 0.18）；**略欢快**的**环境 / 低频器乐**（轻琶音、木吉他拨弦、轻打击、低频 pad）；禁综艺式强鼓点、禁人声。
- **开头留 1–2 秒现场声**：成片前 1–2s 先放现场 / 原声，音乐再进入；不要一上来就 BGM。
- **音乐进入后始终低于说话声并自动 duck**：以 VO 为 sidechain 做 `sidechaincompress`（threshold=0.015, ratio=12, attack=0.020, release=0.40, detection=peak）；BGM 永远不可盖住 现场 / 对谈 / 旁白 / 环境 前四级。
- 退音乐留真实声：反思 / 情绪 / 现场高点段按帧精确硬切 BGM 归零（隔离 BGM 轨 RMS 必须为 0），真实声保留；结尾按片自然淡出，不追加煽情爆点。
- 输出：44100Hz 单声道；总时长与无声源一致（±1 帧）。

---

## F. 转场

- **以利落硬切（cut）为主**。
- **最多用极短 4–6 帧叠化**（cross-dissolve）做平滑；更长叠化、fade、flash 一律不用。
- **不做无意义 whoosh、擦除（wipe）、滤镜秀、速度渐变、电影黑边、插件转场**。
- 每一处效果（含 4–6 帧叠化）都必须服务于内容衔接，没有叙事理由就不用。

---

## G. 参照旧片但不复刻

- 使用之前世斐成片的**亮蓝字幕样式**与**声音节奏**（duck、退音乐、开口留现场声）作视觉 / 听觉参照，保证账号统一。
- **不要复制旧项目的镜头、时间线或结构**：每条片用独立的证据、问题链与结尾；素材不足时诚实留白或缩小命题，不靠复用旧片伪装成新成片。
- 跨片共享素材必须换证明任务、起止点、声音与叙事角色。

---

## H. 交付前硬校验（针对本指标）

- [ ] 逐镜核算：人 ≥ 80%、多多本人 ≥ 60%、landscape ≤ 20%、图 : 视频 = 3 : 7。
- [ ] 画面去重复跑：任意两段汉明 < 10 或 直方图相交 > 0.92 即不合格。
- [ ] 成片时长落在 1:50 – 2:30，且对镜 / 原声主干为 1.2×。
- [ ] 开口 1–2s 为现场声；BGM 全程低于人声（隔离轨验证）；退音乐段 RMS = 0。
- [ ] 字幕：亮蓝 / Bold / 暗边、≤ 10 字 / 屏、不遮嘴 / 动物 / 关键信息、浅背景可读。
- [ ] 转场全为硬切或 ≤ 6 帧叠化；无 whoosh / 擦除 / 滤镜秀。
- [ ] `ffprobe` 确认可播；联系表标注退音乐段、重点字卡、各段占比。

## I. 程序化构建技术备忘（V07b 返工沉淀）

- **原始相册若缺多多本人视频**：先用 face_id 扫描所有候选相册（含 `以前照片/`、`旅行视频/` 等子目录），再按硬指标重新配比，不要被人为分相册限制。
- **人脸感知切入点**：对每段候选视频用 insightface 扫描 4–6 个等分帧，找多多 face embedding 距离最小的时刻作为切入点；切入后需 `clamp` 留出目标时长余量，避免短视频被切到只剩尾部。
- **短视频精确时长补齐**：源视频短于目标 4.45s 时，用 `-stream_loop -1` 循环补齐到精确时长；烘焙滤镜必须采用 `scale=720:1280:force_original_aspect_ratio=increase,crop=720:1280,setsar=1`，避免依赖 ffprobe 读取 CloudDocs 视频尺寸。
- **Concat**：使用 concat demuxer 时配 `-c copy`，不可与 `-r 30` 同时用；需保证各段编码参数一致（libx264 / yuv420p / 30fps / no audio）。
- **烧字幕位置**：`-vf subtitles='...'` 必须放在所有 `-i` 输入之后、作为输出视频滤镜，否则会被误解析为输入选项。
- **封面水印**：AI 生成图烘焙前先用 `crop=iw:ih*0.94:0:0` 裁掉底部潜在水印，再统一 9:16 处理。
