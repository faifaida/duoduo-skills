# 世斐成片字幕 + 音乐 + 封面重混

适用于：已有 MASTER 成片需要做字幕样式重设、音乐重混、封面重制，而不改变画面结构。

## 何时使用

- 多多明确要求「字幕换样式 / 一次不超过 X 个字 / 不要拆词」。
- 音乐需要「无歌词、克制、略欢快、自动 duck、某段退掉留真实声」。
- 封面需要与已发布世斐封面风格一致，并重新写标题。

## 字幕铁律

### 样式

- 字体：STHeiti Medium（macOS 自带，对中文黑体友好）。
- 字号：竖屏 720×1280 下 46 px；若输出 1080×1920 封面/审片，等比放大。
- 颜色：亮蓝绿 `#1FCEDD`，ASS 颜色 `&H00DDCE1F`（BGR 字节序）。
- 字重：**Bold = 1**。
- 描边/阴影：低对比暗边 `OutlineColour=&H66000000, Outline=2`；轻阴影 `BackColour=&H55000000, Shadow=1`。
- 位置：竖屏底部偏上，左右各留 40 px 安全边。
- 可读性：在海水、白沙、亮天空、白墙等浅色背景上必须清晰——靠暗边 + 阴影保证，不靠黑底块。
- 不遮挡：绝不让字幕盖住动物、人物的嘴、以及画面关键信息（脸、手、字、标识）；必要时下移或缩短该屏。
- 重点字卡：全片只额外突出 1–3 个真正重要的词 / 句，不铺满金句卡；不替代口播。
- 精确配比与转场上限见 `production-spec.md`（本文件聚焦重混工作流）。

### 分块

- 每屏不超过 **10 个汉字**。
- 按词组/短语边界断句，**绝不拆词**。
- 单词（如人名、地名）可单独成屏。
- 标点并入当前块，不单独占屏。
- 实现：用 `jieba.cut` 做 greedy 打包，时间窗内在原句起止之间顺序均分。

### ASR 词级时间戳 → 字幕（没有现成 .ass，只有 faster-whisper 词级时间戳时）

1. 把 ASR token 按时间顺序拼成全文字符序列，并为每个字符记录 `(start,end)`（token 内字符共享该 token 时间）。
2. `jieba.cut(full_text)` 得到真实词序列；以**词为原子单位** greedily 打包成 ≤10 字/行，**绝不在词中断开**（jieba 已将"中国旅行团/中国人/行李箱"等合成整词，行尾只落在词边界）。
3. 每行时间 = 该行覆盖字符的 ASR 时间 `min/max`（按字符下标回映射），首尾各加 `LEAD≈0.03s`。
4. **⚠️ 坑（Tuas 实战，2026-08-23）**：ASR 词级时间戳几乎无停顿（本片 778 个间隔仅 1 个 ≥0.55s）。若直接"累计到 10 字就断"会盲切到词中间，产出"海关排/队一个""中国旅/行团"这类拆词断句。**必须用 jieba 分词后再成行，不能用字符数盲目截断。**
5. 受保护词（马来西亚/中国人/海关/尊老爱幼/护栏/叉腰）靠 jieba 天然成词保证不被拆。
6. 断句自检：每行 ≤10 字、无 `\n`、且任一受保护词要么整行出现要么不出（不被跨行拆断）。

### 交付校验

- 0 块超过 10 字。
- 时间码单调递增，不重叠。
- 无 ASS 非法时间格式（秒字段最多 2 位整数，如 `00.14` 而非 `000.14`）。
- ASS 文件中只保留一个 `[V4+ Styles]` 块，避免 libass 因重复样式名渲染错误。

## 音乐铁律

### BGM 选材

- **无歌词**。
- **克制**：peak 不超过 0.18，避免铺底 pad 压过人声。
- **略欢快**：可用轻琶音、木吉他拨弦、轻打击，但禁止综艺式强鼓点。
- **环境 / 低频器乐**：偏好轻环境垫 + 低频 pad / 木吉他，避免高频亮闪闪的旋律抢戏。
- **开头留 1–2 秒现场声**：成片前 1–2s 先放现场 / 原声，音乐再进入；不要一上来就 BGM。

### 混音链（ffmpeg filter_complex）

```text
# 1. BGM 先按 VO 做 sidechain 自动 duck
[bg0][vo]sidechaincompress=threshold=0.015:ratio=12:attack=0.020:release=0.40:makeup=1:detection=peak[bgd]

# 2. 需要退音乐留真实声的段落硬切归零（例：抗议现场 8.47–18.68s）
[bgd]volume=0:enable='between(t,8.47,18.68)'[bg_g]

# 3. 结尾淡出（例：112s 开始 5s 淡出）
[bg_g]afade=t=out:st=112:d=5[bg]

# 4. LIVE/现场声轨延迟对齐到退音乐窗口
[live]atrim=0:10.21,...,adelay=8470|8470,apad[live_out]

# 5. 全部混音 + 限幅
[vo][bg][sfx][live_out]amix=inputs=4:duration=first[amix];[amix]alimiter=limit=0.95[out]
```

### 关键参数含义

- `threshold=0.015`：VO 几乎一出现就触发 duck。
- `ratio=12`：BGM 被压到约 1/12。
- `attack=0.020`：20ms 快速下压，不吞字。
- `release=0.40`：400ms 缓慢恢复，自然呼吸感。
- `detection=peak`：按峰值检测，比 RMS 更跟口语节奏。

### 退音乐窗口

- 必须精确到帧（例：8.47s / 18.68s）。
- 退掉的是 BGM，不是 VO/SFX/LIVE；**真实声必须保留**。
- 隔离 BGM 轨验证：退音乐段 RMS 必须为 0.00000。

### 输出规格

- 采样率 44100 Hz，单声道，pcm_s16le 中间文件；最终成片 AAC 128kbps mono。
- 总时长须与无声源完全一致（±1 帧）。

## 封面铁律

### 画幅与平台

- 竖屏 9:16，推荐 **1080×1920**。
- 用于 小红书 / 抖音 / 视频号 首屏。

### 风格（与世斐已发封面一致）

- 用旅行现场真实照片做底图，保留真实肤色、自然光、轻微手持感。
- 亮蓝绿 `#1FCEDD` 只做强调：标题盒、地点标签、少量点缀。
- 标题用**粗体黑字**压在 cyan 圆角矩形容器上，容器带轻软阴影。
- 地点标签：顶部小圆角胶囊，黑字 cyan 底。
- 多多形象：优先用同集素材里的好看照片；可做成圆形/圆角裁切贴纸，加白边和黄色放射短线点缀。
- 不套电影黑边、不重 LUT、不用无意义装饰。

### 标题写法

必须同时满足：

1. **有冲突**：可见的异常、风险、反差、反常识。
2. **总结内容**：让观众知道这条片讲什么具体事件。
3. **感受陌生化**：把熟悉感受用陌生方式说出来，或把陌生现场用个人化感受说出来。
4. **引发好奇**：留一个可追问的缺口，而不是陈述结论。

好标题示例（本片）：

- 「敢走的人，先被赶下车」—— 翻转旅行 cliché，冲突（被赶下车）+ 主题（敢走/选择）。
- 反例：「格鲁吉亚旅行记录」「我在格鲁吉亚学到了自由」—— 无冲突、无具体事件、无追看缺口。

## 工具链

- ffmpeg 7.1+：`drawtext` / `subtitles` / `sidechaincompress` / `afade` / `volume` / `amix`。
- Python：`jieba`（中文分词）、PIL/Pillow（封面合成）、`numpy`/`wave`（RMS 校验）。
- 字体：`/System/Library/Fonts/STHeiti Medium.ttc`（macOS 中文黑体，.ttc index 0 可用）。

## 生产闸门

交付前必须：

1. 实际播放成片，确认字幕闪现节奏不急促、不遮挡人脸。
2. 抽帧确认字幕颜色 = #1FCEDD、Bold、暗边可见。
3. 隔离 BGM 轨，确认两处退音乐窗口 RMS = 0。
4. 生成联系表 / 审片 HTML，标注退音乐段和字幕块数。
5. 封面在 9:16 缩略图尺寸下 3 秒内可读。
