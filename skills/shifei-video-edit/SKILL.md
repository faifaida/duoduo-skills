# 世斐视频剪辑

把世斐剪成真实世界的理解，而不是旅行景观。当前主线是：**这个人让我看懂了这里。**

先读 `references/editorial-system.md`。人物对谈读 `references/people-interview.md`；要复刻 Sri Lanka / Oday 横屏成片时再读 `references/oday-horizontal-recipe.md`；Field Notes 或旅行旁白读 `references/field-notes.md`；开剪前和交付前按 `references/production-qa.md` 执行。

## 账号边界

- 世斐的叙事主体是人物、地点、事件、连接与真实现场：外部世界。
- 多多 OS 的叙事主体是多多的人生系统：不要混剪。
- DUODUO WEAR 的叙事主体是产品、身体、泳衣和品牌：不要把这些视觉当世斐的主叙事。
- 同一素材可共享，但必须换证明任务和起止点；不得让同一段镜头承担两个账号完全相同的叙事。

## 开剪流程

1. 确认账号、片型、画幅、交付平台、人物及事实来源。能从项目资料得到的，不反复问用户。
2. 对所有人声做带时间戳的转录，标出 speaker、听不清处、笑、停顿、沉默和打断。不要让自动字幕替代人工校对。
3. 建立 Paper Edit：先用声音确认故事，再做画面。人物片先做 Radio Cut。
4. 只用能证明正在说什么的画面。优先人物脸、真实反应、同一空间、同一事件；素材不足时保留脸或诚实留白，不用漂亮空镜掩盖缺口。
5. 再做声音、字幕、调色、B-roll、概念卡和封面。每次改时长后必须重对字幕和音画。
6. 导出前运行 `scripts/verify_delivery.sh <master.mp4>`，再抽看开头、每张卡、每位说话者、转折和结尾。

## 人物片不可谈判规则

- 不剪成问答摘录或人物语录机；从一个人如何做选择、被什么限制、如何与这里发生关系来剪。
- 一个人可以剪成多期；每期先定义一个可独立成立的主题问题，而不是按原始拍摄时间顺序或一次采访的完整度切分。不同期必须使用不同证据、不同问题链和不同结尾，避免同一段素材换标题重复发布。
- 不删除多多的问题再直接进入对方回答。多多是场内人物，不是隐形记者；保留有效追问、笑、愣住、安静和连接。
- 先让人物成立，再给宏观含义。人物与国家、战争、身份、爱情、护照、医疗、法律等信息一律只说原片可证实的部分。
- 结尾必须是人物自己的答案或真实收尾动作；禁止用一句抽象总结硬切。

## 复刻「Sri Lanka / Oday」对谈

这是世斐 People 的特殊横屏版本，优先级高于通用竖屏规范：

- 16:9 横屏，1920×1080，30 fps，H.264，绝不留黑边。
- 多多在左、受访者在右，两人持续同框；说话者可略亮，另一侧略收，但不切掉任何一方的反应。
- 字幕准确双语：英文原句在上、简洁中文在下；多多的问题必须逐条出现。置于对应人物头顶上方：多多左上、受访者右上。
- 字幕用粗体思源宋体/宋体感，31 px；亮蓝绿默认 `#35EDFF`（可沿用既有亮蓝绿）；字重至少 800。明亮窗景、白墙或绿植背景下使用 1 px、85% 不透明度的细黑描边提升可读性；不用黑底、粗描边或重阴影。
- 每一个新问题前都插一张概念卡：冻结真实画面、压低到静音、中文逐字出现、每个字配非常轻的打字声；卡结束后才恢复语音，禁止出现“卡在播但嘴还在动”。
- `HUMMUS` 与 `在这里，展示这里` 是可保留的主题卡样式，但概念卡只服务问题或真正的高潮，不要滥用。
- 色彩是温暖克制的 Fuji / Classic Chrome 倾向：暖肤色、柔和对比、略压高光；真实地点和肤色优先，禁止强 LUT、脏黄、过饱和或电影黑边。
- 降噪只减背景，不拿走呼吸和人声空气感。禁止重门限、强去混响、白噪声填充或让声音发闷。删气口和停顿时，做真实硬切并同步移动视频与字幕；不靠加速糊弄。

## 交付

交付一个可播放的 MASTER、字幕文件（SRT/ASS）、CUT_NOTES、USED_ASSETS 和 UNUSED_GEMS。输出文件必须能被 `ffprobe` 正常读取；没有 `moov` atom、字幕漂移、卡点音画不同步、缺提问字幕或突然结束，一律不交付。
