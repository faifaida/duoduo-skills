# Brand DNA — 多多品牌基因（Design Skill 底层规范）

> 这是多多的审美世界观，**不是单一品牌的配色卡**。未来任何 AI 做多多的视觉（个人网站、知识库、产品页、纹身/首饰/服装实验、社媒图），都先读这份，再读对应场景文件。
> 核心理念：**限制 AI 自由度 = 质量**。AI 不许自由发挥，必须查手册、按 token 与母题行事。
> 风格一句话：**野而温柔、原始而精致、自由而有骨头、手作而有世界。**

> 比例原则：**基底（米+蓝绿）60% · 暖调（沙/陶）30% · 神秘点缀（赭金）10%**。

### 字体令牌
- `--font-display`: `'Fraunces', 'Noto Serif SC', serif` — 英文大标题/展示体（书卷气衬线）
- `--font-serif-cn`: `'Noto Serif SC', 'Source Han Serif SC', serif` — 思源宋体，中文标题+正文（全衬线书卷）
- `--font-hand`: `'Caveat', cursive` — 手写批注、便签、标签（boho 手作感）

### 字号系统（fluid）
- Hero 大标题: `clamp(2.8rem, 7vw, 5.5rem)`
- Section 标题: `clamp(1.6rem, 4vw, 2.6rem)`
- 卡片标题: `1.15rem ~ 1.4rem`
- 正文: `16px`（全衬线，行高 `1.9`）
- 辅助文字: `0.78rem ~ 0.85rem`
- 大装饰数字/符号: `clamp(3rem, 8vw, 7rem)` + `opacity: 0.12~0.2`

### 间距 / 圆角 / 阴影
- Section 间距: `clamp(80px, 12vh, 160px)`
- 内容块间距: `clamp(40px, 6vw, 100px)`
- 卡片 padding: `clamp(28px, 3vw, 44px)`
- 元素 gap: `clamp(24px, 3vw, 48px)`
- 圆角: `14px`（卡）/`20px`（大卡）/`50%`（圆形头像/符号）
- 阴影: 轻量 `0 3px 16px rgba(26,26,20,.06)`；引用卡 `0 8px 40px rgba(26,26,20,.05)`
- 内容宽: `max-width: 1300px` + `margin: 0 auto`

- 头像放 `assets/avatar.jpg`（正方形，≥400×400）。

## 🔤 字体基因

### 核心原则
- **全衬线书卷**：标题与正文都用衬线，产生书卷、自然、有重量的气质。
- **中英文搭配**：英文（Fraunces）做装饰/标签/展示，中文（思源宋体）承载内容。
- **手写体点缀**：Caveat 仅用于便签、批注、手绘标签，不用于正文。
- **字号对比极端**：大的要很大，小的要真的小。

### 推荐字体池
| 场景 | 推荐 | 备注 |
|------|------|------|
| 英文展示/大标题 | `Fraunces` (含 italic) | 书卷衬线，有品质 |
| 英文手写/批注 | `Caveat` | 手绘感标注 |
| 中文标题+正文 | `Noto Serif SC` / `Source Han Serif SC`（思源宋体） | 全衬线书卷 |
| 中文备选 | 系统衬线栈 | 无本地字体时 fallback |

## ✨ 气质关键词（vibe）

设计出来的东西应该让人觉得：
- **野而温柔** — 原始、有力量，但不粗鲁；有手作温度。
- **手作而有世界** — 像旅行带回来的物件，有地理与文化的厚度。
- **不像 AI** — 最高优先级约束（见禁忌）。
- **有设计师眼光** — 间距精确、色彩克制、母题统一。
- **灵性但不玄虚** — 符号承载意义（太阳/月亮/曼陀罗/图腾），不是装饰噪点。
- **个人品牌感** — 一看就知道是"多多的"。

## 🪞 纹身 / 灵性符号 / 部落 —— 第四审美轴（重点）

> 你收的图里有一条独立且强烈的线：**纹身手稿、灵性符号、部落原始图腾**。它不该只当装饰，而是多多的"意义系统"。AI 做视觉时应主动调用这一层的母题。

### A. 灵性符号（spiritual symbols）
太阳 / 月亮 / 星辰、曼陀罗、神圣女性、阴阳眼、三叉戟、莲花、螺旋、护身符 / 塔罗、柏柏尔符号（Berber）、萨满图腾。
- 用法：作为线描 SVG 母题，单色（ink / ochre / clay），置于分区起首、页眉水印、卡片角标。
- 气质：神秘、对称、有仪式感；避免"星座运势"式的俗艳。

### B. 部落 / 原始（tribal / primitive）
岩画涂鸦（太阳/星星/举手人形/蜗牛/螺旋）、点刺（dotwork）技法、几何部落图腾（对称人面/波浪/栅栏）、箭头/羽毛、编织绳结。
- 用法：作为纹理底、分隔带、边框母题；可"错落叠压"制造拼贴感（更野方向）。
- 气质：古老、原始、手工感；用牛皮纸/米底增强仪式感。

### C. 单线融合（single-line fusion）
女人 × 动物（狮子/狼/豹/鸟/兔）连续一笔线条、圆形框架、留白极多。
- 用法：官网 Hero、关于页、力量表达；代表"女性内在力量"。
- 参考母题：闭眼女人与咆哮狮子、女人与狼圆形融合。

### D. 自然（nature，贯穿全品牌）
海浪、山、棕榈、贝壳、植物藤蔓、佩斯利（paisley）。
- 用法：背景晕染、分隔曲线、线描点缀。

### 母题调用规则
1. 每个页面/分区**至少**有一个明确母题（太阳/浪/曼陀罗/图腾之一），不许"无母题通用模板"。
2. 母题一律**线描**（stroke，非填充块），单色，与底色对比克制。
3. 灵性符号要有"意义"，不要随机撒点；同一符号在站内重复出现形成识别。
4. 可从 `assets/motifs.svg` 取用现成线描母题。

## 🎨 配色扩展原则

当主色不够用时：
- 背景永远偏暖：`--cream` `#F1E9DA`（米白麻·主背景）、`--cream-deep` `#E8DCC8`（米色·玉髓暖沙·底）
- 文字永远非纯黑：用 `--ink` `#2A2620` 或 `--ink-light`
- 绝不用纯黑 `#000` / 纯白 `#fff` 作大面积
- 暗色场面底色：`--teal-deep` `#0F3D3A`（仅 HTML 全屏页；卡片场景禁止深色底）
- 径向渐变制造层次（海浪晕染感），不用纯平色块做大背景
- 神秘点缀（ochre/clay）永远 ≤10%，不做主色

## 🚫 通用禁忌清单（anti-AI-template）

| 类型 | 禁止 |
|------|------|
| 配色 | 蓝紫渐变、cyan、neon、纯黑白、AI 常用的冷灰蓝调、多色渐变背景；占位色块用纯色 `--cream-deep` 或 `--sand` |
| 深色版面 | 仅 HTML 全屏页可用 `--teal-deep` 暗面板；3:4 卡片场景禁止深色底 |
| 字体 | Inter / Roboto / Arial 等 overused 无衬线（除非终端场景）；monospace 充当"技术感"；用 sans 当中文正文 |
| 布局 | 所有 section 居中、千篇一律卡片网格、cards 嵌套 cards、对称 50/50 无张力 |
| 动效 | bounce / elastic、animate width/height、无限循环动画 |
| 装饰 | glassmorphism、圆角矩形+阴影千篇一律、渐变文字、AI 光效、border-left 竖线引用块（Notion/飞书式） |
| 母题 | 无母题通用模板、随机撒灵性符号无含义、母语题与内容无关 |
| 整体 | 看起来像 AI 生成的通用 Landing Page 模板 |
| 边框 | 强调色装饰边框细于 40px（统一 40px，不得更细） |
| 排版 | 行间距/字间距异常（过松/过紧）；默认样式渲染 |
| 图片 | AI 生成的 stock photo 风、过度滤镜、无意义装饰图；**AI 生成图底部自带的「图片由AI生成」水印（永远禁止留存）** |
| 默认样式 | 默认 `<blockquote>`、默认 border-left 引用块、无样式 `<ul>/<ol>`、默认 `<table>`——所有组件必须从 `components.md` 选用 |

### 🚫 AI 生成图水印红线（硬规则，不可违背）
- 用 ImageGen / 任何文生图工具产出的图，**输出必定带「图片由AI生成」水印**，参数压不掉。
- **禁止**把带水印的图交付/上线/发社媒。这是用户明确红线：「永远不要有这几个字」。
- 可靠去水印方法（已验证）：**硬切底部 50px + 品牌色渐变覆盖**。
  - 主图（深色场景）：裁掉底部 50px，新底 25px 用 `#151a2e`(night) 渐变铺满。
  - 详情/卡片图（米底场景）：裁掉底部 50px，新底 25px 用 `#f1e9da`(linen) 渐变铺满。
  - 示例（PIL）：`img = img.crop((0,0,w,h-50))` 后底部 25px 填品牌色线性渐变。输出实际约 768×974。
- 更优：生图时在 prompt 里写明「无文字、无水印、无签名」，再走上面的硬切兜底。

### 自检问题
做完设计后问自己：
1. 截图发社媒，会不会被评"又是 AI 做的"？
2. 能不能一眼认出这是"多多"的（蓝绿+米+线描母题+全衬线）？
3. 有没有哪个部分"见过很多次了"？
4. 有没有明确母题？符号有没有意义？

## 📐 通用间距 / 响应式

- 间距全部用 `clamp()` 做 fluid。
- 断点：900px（两栏→单栏）、600px（字号微缩）。
- 移动端是"重新排列"不是"缩小"；不隐藏内容（adapt 不 amputate）。
- 尊重 `prefers-reduced-motion`。

## 🔍 细节规范
- 选中文本高亮：`::selection { background: var(--ochre); color: var(--ink); }`
- 链接悬停：用强调色底色块或下划线，不用变色。

*This is the foundation. Every scene file builds on top of this.*

- 其余 token（间距/圆角/阴影/母题规则）与上方 §设计令牌、§母题调用规则完全一致，照用即可。
