# 场景：个人网站 / 品牌主页 / 知识库页 / 产品页 / 活动 Landing

> 长页面（多 section，可滚动）。基调：野而温柔、全衬线、蓝绿+米、线描母题。
> 配套模板：`assets/template-landing.html`。布局从 `references/layouts.md` 选 3~5 种，每 section 不同。

## 页面骨架（推荐顺序）
1. **Hero**（布局 #1 不对称双栏 / #8 全屏卡片 / #9 单栏纵向）— 大标题 + 一句话定位 + 母题视觉（女人×狮 / 曼陀罗线描）。
2. **价值/能力**（布局 #3 三等分卡 / #10 auto-grid）— 每个卡角标一个灵性符号（月/星/莲）轮换。
3. **故事/理念**（布局 #6 深色面板 / #13 分栏对称）— 金句用 #3/#6，禁 border-left 引用块。
4. **作品/产品**（布局 #10 / #21 作品卡 / #22 产品卡）。
5. **CTA 邀请**（布局 #11 品牌色面板）— 用 #18 CTA 按钮，clay 或 teal 底。
6. **页脚** — 母题水印（同一符号重复，形成识别）+ 手写体联系方式。

## 必做
- 每 section 至少 1 个明确母题（太阳/海浪/曼陀罗/图腾/女人×狮），单色线描，与底色对比克制。
- 配色严格走 `brand-dna.md` token；暗色面板 ≤1~2 个且只用 `--teal-deep`，非卡片场景。
- 字体：英文 Baskerville 栈（展示），中文思源宋体（正文），手写体 Caveat 仅批注。
- 间距全 `clamp()`；断点 900px 两栏→单栏、600px 微缩；移动端「重排不隐藏」。

## 禁止
- 所有 section 居中、千篇一律卡片网格、对称 50/50 无张力。
- 默认 `<blockquote>`、`border-left` 引用、无样式列表/表格。
- glassmorphism、渐变文字、AI 光效、bounce/elastic 动效。
- 任何带「图片由AI生成」水印的图（见 SKILL.md 水印红线）。

## 自检
- 截图发社媒，会不会被评「又是 AI 做的」？能否一眼认出「多多」？
- 每个 section 布局是否都不同？母题是否都有意义？
