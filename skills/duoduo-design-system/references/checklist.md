# 质量门 Checklist（多多版）

> 交付前逐条核对。P0 不过必须改；P1 尽量过；P2 加分。
> 改写自 esther-design-system/checklist.md，增加「母题」维度。

## P0 必须全过
- [ ] 所有颜色来自 `brand-dna.md` token，无纯黑 `#000`/纯白 `#fff` 大面积、无 AI 冷灰蓝/neon/蓝紫渐变
- [ ] 字体为全衬线（思源宋体 + Fraunces），无 Inter/Roboto/Arial 等 overused 无衬线作正文
- [ ] **每个分区都有明确母题**（太阳/海浪/曼陀罗/图腾/女人×狮之一），无"无母题通用模板"
- [ ] 灵性符号有意义、单色线描，非随机撒点
- [ ] 无 HTML 默认样式：无默认 `<blockquote>`、无 `border-left` 引用块、无无样式 `<ul>/<ol>`、无默认 `<table>`
- [ ] 每个 section 布局不同（参考 `layouts.md`）
- [ ] 间距用 `clamp()`，无异常行距/字距
- [ ] 可直接浏览器打开，移动端（<900px）正常重排不隐藏内容

## P1 应过
- [ ] 母题从 `assets/motifs.svg` 取用，统一线宽与单色
- [ ] 暗色面板 ≤1~2 个，仅用 `--teal-deep`，且非卡片场景
- [ ] 动效组件 ≤2 个，仅 Hero/结尾，带 `prefers-reduced-motion` 降级
- [ ] 链接悬停用底色块/下划线，非变色
- [ ] 选中文本高亮用 `--ochre`

## P2 加分
- [ ] 母题在站内重复形成识别（如页眉水印同一符号）
- [ ] 手写体（Caveat）仅用于批注/标签
- [ ] 径向渐变制造海浪晕染层次
- [ ] 截图发社媒不会被评"又是 AI 做的"，且能一眼认出是"多多"
