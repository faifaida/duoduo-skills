# 场景：App 型 / 功能型（看板 / 书架 / Canvas）

> 工具类界面（非营销页）：个人看板、知识库书架、可视化画布、Dashboard。
> 模板：暂无独立模板，从 `assets/template-landing.html` 起步，按本文件改造。布局参考 `references/layouts.md` #14/#15/#16。

## 结构
- **顶栏**：#9 导航栏（fixed + 毛玻璃），品牌色细线分隔。
- **主区**：#14 Tab 切换 / #15 无限画布（点阵网格背景）/ #16 Sticky 编号侧栏 + 大图卡。
- **卡片**：#1 卡片库（1A~1E），hover 用 #32 悬停揭示卡；动效 ≤2 个且带 `prefers-reduced-motion` 降级。
- **列表/数据**：#35 交互清单 / #19-#20 对比表（禁止默认 `<table>`）。

## 必做
- 仍是多多 token + 全衬线 + 线描母题角标（#60 Motif Badge）。
- 功能优先，视觉克制；暗色仅用于个别面板（`--teal-deep`），不整页黑。
- 响应式：900px 收起侧栏，600px 单列。

## 禁止
- 把营销页的 Hero/大留白搬进工具界面。
- glassmorphism 滥用、bounce 动效、默认表格/列表样式。
- 带水印 AI 图。
