# 场景：图文卡片 / 小红书图文 / 闲鱼图（3:4 社媒卡）

> 单图或一组图（非长页面）。尺寸 **1080×1440（3:4）**。用途：小红书笔记封面、闲鱼商品图、朋友圈九宫格、知识星球配图。
> 配套模板：`assets/template-cards.html`。这是站外分发最高频场景，优先保证「一眼是多多」。

## 版式骨架（自上而下）
1. **顶部品牌条**（高 ~80px）：左侧母题符号（太阳/曼陀罗线描）+ 右侧手写体小字（如「世斐 · 她局」）。
2. **主标题区**（占 40%~50%）：大字 Baskerville/思源宋体，1~2 行；可叠一个巨大母题水印（opacity 0.08）。
3. **副文案/卖点**（3 行内）：思源宋体，行高 1.9，≤3 个短 bullet。
4. **中部视觉**：照片或线描插画；若用 AI 生成图，**先去过水印**（SKILL.md 红线：硬切底 50px + 品牌色渐变）。
5. **CTA / 价格条**（底部 ~120px）：clay 或 teal 圆角块，写「¥49 起」「私信我」等；文字 `#faf6ee`(paper)。
6. **底部留白 ~50px**：专留给去水印处理，天然米底，**绝不在这里放任何文字或水印**。

## 硬规则
- **3:4 卡片禁止深色底** — 背景必须米（`--linen #f1e9da` / `--cream #f1e9da` / `--paper #faf6ee`），文字 `--ink`/`--graphite`。
- **40px 线描边框**：外框统一 40px 单色线（ink/ochre/clay），不得更细；四角可加部落点刺角标。
- 母题线描、单色、与底对比克制；每卡至少 1 个明确母题。
- 字体：标题 Baskerville 栈，正文思源宋体；手写体 Caveat 仅标签。

## 禁止
- 深色背景卡片、渐变文字、glassmorphism、AI 光效。
- 「图片由AI生成」水印（永远禁止）。
- 默认样式、千篇一律居中卡片网格。

## 输出
- 导出 1080×1440 PNG；组图保持同一边框/母题/字体体系（识别统一）。
- 闲鱼首图 + 详情图 01~05 共用此模板换文案即可（见 `闲鱼上架稿` 类交付物）。
