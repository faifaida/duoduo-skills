# QA Checklist

## 文字

- [ ] 所有中文无错字、伪字和乱码。
- [ ] 标题、CTA、数字、专有名词与原文一致。
- [ ] 正文在 1080 画布上不小于 28px。
- [ ] 无一行仅剩 1–2 个汉字的难看断行。
- [ ] 英文拼写与大小写正确。
- [ ] 压缩文字未改变作者立场。

## 结构

- [ ] 两张图同尺寸。
- [ ] Part 1 与 Part 2 连续但不重复。
- [ ] 每张 5–8 个主要阅读块。
- [ ] 每 350–500px 有呼吸区。
- [ ] CTA 明确可执行。

## 视觉

- [ ] 米白卡有棉麻纤维和手工纸感。
- [ ] 纹理没有影响阅读。
- [ ] 海洋与纸张比例平衡。
- [ ] 亮蓝只做高亮。
- [ ] 暗红/棕色没有大面积抢占。
- [ ] 装饰没有遮挡正文。
- [ ] 照片与纸张阴影方向一致。

## 真实性

- [ ] 真实照片与生成图片已区分。
- [ ] 没有用生成图冒充真实项目现场。
- [ ] 未虚构产品状态或成果。
- [ ] 无未经授权的个人隐私。

## 技术

- [ ] sRGB。
- [ ] PNG 清晰，无压缩伪影。
- [ ] 公众号中缩放后仍可读。
- [ ] 文件名清楚：part-01 / part-02。
