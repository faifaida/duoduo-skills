# 批量 AI 精修月度复盘（journal-review-refine）

## 触发场景
- 用户有一批**自动生成的复盘草稿**（结构合法、含占位符如 `（待 AI 精修）`、把日期当选题的垃圾），要升级成叙事式、有洞察的精修版。
- 用户说"升级ai精修""精修一下这些复盘""把草稿提质"。

## 核心思路
不要在主上下文里逐篇读全部源材料（容易爆 context）。改为：
1. **预处理**：用脚本把原始「daily/素材」按时间片（如 YYYY-MM）聚合成紧凑的 `raw/<片>.md`，每篇只留有效正文 + frontmatter 关键字段。
2. **分片并行**：派多个 `general-purpose` 子代理（Agent 工具），每代理负责一个时间片区间（按年或半年），读"金标范例 + 该片素材 + 对应草稿"，用 Write 覆盖重写。
3. **校验**：全量脚本检查占位符残留、YAML 合法性、必需字段/章节、垃圾内容。

## 步骤

### 1. 预处理脚本（参考 /tmp/preprocess_reviews.py 思路）
- 遍历 `01 Daily/<YYYY>/*.md`（2026-08-03 起日记按年归档在 `01 Daily/<YYYY>/` 子目录，用 `01 Daily/*/*.md` 递归匹配），按 `YYYY-MM-DD` 取月份分桶。
- 对每个文件：解析 `---` 间的 frontmatter（focus/people/location/occasion 等）+ 正文各 `## 段落`，丢掉 callout(`>`)、模板占位行、空段落。
- 输出 `/tmp/review_raw/<YYYY-MM>.md`，每篇 daily 形如：
  `## 2024-03-01 — focus: 💫职业,🌍资源 | people: 欢哥` + 各段落文本（限行数防膨胀）。
- 同时产出 `manifest.json`（年→月份列表），用于分片派代理。

### 2. 派并行精修子代理
- 先选 1 篇已达标的"金标范例"（用户认可的高质量版），让所有代理都读它学语气/结构。
- 按年（或 12 篇重的年拆成上下半年）分片，每片 1 个 Agent 调用，prompt 含：
  - vault 绝对路径；金标范例路径；该片 `/tmp/review_raw/<月>.md` 素材清单；要重写的草稿路径清单。
  - **硬性规则**（务必写进 prompt）：
    - 用 Write 覆盖整个文件，保留 T07 用途 `> [!note]` callout。
    - 必需章节：本月一句话 / 八课题速览(表格 8 行全列，证据带真实日期) / 长期模式 / 矛盾·盲区 / 资产沉淀(六类) / 北极星4问 / 12 个真实内容选题 / 4 个可复用方法SOP / 杠杆行动+实验 / 信号与数据。
    - frontmatter YAML 合法：`focus` 仅保留当月有真实信号的课题，且为 `[[八个课题#名称]]` 链接（用 YAML 块列表）；填真实 `energy_summary/location/key_people/related_project/source_notes`。
    - 严格消除 `（待 AI 精修）`、`自动数据草稿` warning、把日期当选题的垃圾。
    - 用真实声音写作；推断标 `[AI推断]`/`[待验证]`，不编造素材外事件。
  - 明确"只重写分配给你的月份，不动其他文件"。

### 3. 校验（python，pyyaml）
- `grep -l "待 AI 精修"` 应为 0；`grep -l "自动数据草稿"` 应为 0。
- 对每篇 frontmatter `yaml.safe_load` 全合法；`focus` 每项去 `[[八个人生课题#` 后名字须在白名单内。
- 必需章节字符串全在；`本月 12 个内容选题` 后无 `^\d+\.\s*20\d{2}-\d{2}-\d{2}$` 这类日期垃圾。

## 注意事项
- 子代理**只写自己分配的月份文件**，不同代理文件不重叠 → 无写冲突，可全并行。
- 素材预处理是关键：直接读全部 daily 会让单代理 context 爆炸；先压缩成 per-month raw。
- 课题锚点名称（含 emoji、全角斜杠 ／）必须**原样**，白名单校验能抓 typo。
- 早期月份素材可能仅 1 篇 → 代理应做深、宁缺毋滥，不要硬凑 12 选题。
- 已精修的月份要在分片时**排除**，避免覆盖好文件。

## 反模式
- ❌ 在主上下文逐篇读 500+ 源文件再写 → context 溢出。
- ❌ 让代理只 Edit 局部 → 残留 `（待 AI 精修）`/warning callout → 必须整文件 Write。
- ❌ focus 写成自由文本而非 `[[课题#名称]]` 链接 → 破坏图谱链接。
