# DUODUO WEAR 海报技术规范

## 1. 画布尺寸

| 用途 | 宽度 | 高度 | 比例 |
|---|---|---|---|
| 默认社媒竖图 | 768 px | 1074 px | 约 3:4 |
| 手机壁纸/加长竖图 | 768 px | 1274 px | 约 3:5 |

注：768×1074 是黄金标准，与参考资产 `ref_poster_flatlay_768x1074.png` 一致。加长版仅在用户明确要求时使用，footer 高度占比保持不变。

## 2. 品牌色

| 颜色名 | 值 | 用途 |
|---|---|---|
| night | `#151A2E` | 文字 logo、深色背景、主标题 |
| linen | `#F1E9DA` | 底部 footer 底色、米色沙滩、纸感背景 |
| teal | `#00B6C5` | 泳衣点缀、系带、强调细节 |
| rust | `#B4553A` | 辅助强调色（少用） |

Footer 必须使用 linen `#F1E9DA`，禁止使用纯白 `#FFFFFF` 或暖米 `#FAF0E6` 替代。

## 3. 底部 Footer 规格

### 3.1 尺寸

- Footer 高度：约 134 px（在 768×1074 画布中占 12.5%）
- Logo 区域：Footer 中央，水平居中
- 顶部渐变过渡：约 30-40 px 的柔和渐变，从画面内容渐入 linen 底色

### 3.2 Logo 组合

- 左侧：蓝色图形 logo（抽象的冲浪者/海浪/人形图案）
- 右侧："DUODUO WEAR" 文字
- 文字颜色：深蓝色/海军蓝，接近 `#151A2E` 或略浅
- 字体：无衬线、大写、字间距适中、现代简洁
- 图形与文字间距：紧凑但可辨识，整体呈一行排列
- 组合位置：footer 水平中央，垂直居中

### 3.3 融合方式

- 不得用硬切直线分隔 footer 与画面
- 顶部必须使用渐变蒙版（gradient mask）从画面内容过渡到 linen 底色
- 渐变方向：从上（透明/画面）到下（linen 实色）

## 4. 字体

- Logo 文字：无衬线现代体（如 Montserrat、Helvetica Neue、Futura 风格）
- 不使用衬线体、手写字体、装饰字体
- 所有文字必须加粗或 medium weight，保证在 footer 上清晰可读

## 5. 图像质感

- 风格：真实摄影/胶片摄影
- 质感：轻微颗粒、自然光影、哑光、去 AI 感
- 光线：自然日光、海边金色逆光或柔和散射光
- 背景：真实沙滩与海水，禁止纯色背景或棚拍背景
- 人物（hero 版）：自然肤色、真实发丝、不磨皮、不过度修图

## 6. 构图锁死项

| 元素 | Flatlay 版 | Hero 版 |
|---|---|---|
| 主体位置 | 画面上半部/中部偏上 | 画面中央偏上，半身 |
| 背景 | 沙滩 + 海水 | 沙滩 + 海水，浅景深 |
| 人物 | 无 | 有，姿势可变 |
| 泳衣 | 平铺展示完整套装 | 上身穿着展示 |
| Footer | 底部 12-15% | 底部 12-15% |
| Logo | 底部中央 | 底部中央 |

## 7. 可变项

唯一允许自由变化的元素：

1. 泳衣设计（款式、颜色、纹理、系带、金属件、图案）
2. Hero 版人物姿势（海边自然姿态）

其他所有元素必须保持与参考资产一致。

## 8. 输出格式

- PNG（默认）
- 质量：高
- 色彩空间：sRGB
- 无压缩伪影

## 9. 文件命名建议

```
duoduo_wear_poster_{layout}_{swimsuit_keyword}_{YYYYMMDD}.png
```

例如：
- `duoduo_wear_poster_flatlay_teal_bikini_20260806.png`
- `duoduo_wear_poster_hero_rust_onepiece_20260806.png`
