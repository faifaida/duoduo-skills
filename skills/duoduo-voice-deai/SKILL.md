# 多多内容 · 去 AI 味 + 原声重写 SOP

本 skill 是「qu-ai-wei（中文）」+「humanize-en（英文）」两个已装 skill 的上层编排，
外加**多多专属原声约束**。单独调用 qu-ai-wei / humanize-en 也能用，但本 skill 把
「用户 2026-07-23 明确的方向」焊死，避免每次重新交代。

## 触发
- 用户要改写/生成多多的内容，且出现「去 AI 味 / 太 AI / 说人话 / 像我本人 / 保留语气」等意图。
- 适用对象：多多个人公司旗下所有公开发文（文字包、视频口播稿、平台 bio、newsletter）。
- 视频脚本/口拨稿/分镜文案 → 先按本 skill 的「视频脚本 / 社媒声纹（duo社媒通用声纹）」一节立结构，再走语种分流重洗。

## 铁律（用户 2026-07-23 明确，最高优先级）

**凡是多多对外发布的文案，一律先过本 skill 重洗——不分平台、不分媒介。**
- 范围：网站（faifaida.com 各页 / 产品页 / landing）、产品（duoduo wear / 她局 / 闲鱼等上架文案）、社媒脚本（小红书 / 公众号 / 视频口播稿 / 分镜 / bio / newsletter）。
- 不可以直接把 AI 初稿或用户草稿原样对外发；必须经济由 qu-ai-wei（中）/ humanize-en（英）/ duo社媒声纹（视频）重洗——保毛边、去 AI 腔、不虚构事实。
- 本 skill 是「最后一道声纹重洗」，不是「让空泛稿自动变成多多」的魔法。

## 不可违反的顶层约束（用户原话）
> 保留原语气原风格和原来的犀利感！！不追求语义通顺语法好逻辑好！！

这意味着：
1. **毛边必须留**：碎片句、断句、`？？？`、`！`、重复强调（很很很 / 完！全！不！垮！）、中英混排（AI / Build in Public / chemistry meeting）、自嘲（我说累了 / 女娲偏心说累了）、具体不抽象、第一人称压倒。
2. **不追通顺**：不要把碎片拼成通顺长句；不修跳脱；不补逻辑衔接；不消除真实口吻的「粗糙」。
3. **犀利优先**：不 hedge、直接判断、遇强越强 / 不平则鸣的劲儿要保。
4. 多多的 9 型 = 4（艺术个体）+ 8（领袖权力型），语气要带「我不准备讨好你」的劲儿。
5. **文艺优先于江湖气（用户 2026-07-24 纠正）**：多多真实声口**不是**「江湖气 / 社会气 / 大哥式口号」。**江湖气禁用样例**：「这叫接班？这叫帮人扛雷。」「现成的路最阴的是…」「你这叫…」这类粗粝断言、人身训诫口吻。**文艺学习样例**（来自真实 journal）：黑海日落「比皮肤温度再低两度的那种感觉」「用手电筒一下一下扒拉石头，从落日呆到黑夜」；模块一收尾「我以前一直在流浪。现在我开始学着建造。」→ 文艺 = **感官具体 + 内省 + 诗意收尾**，同时仍保留碎片 / `！` / 毛边。犀利可以，但要用「具体的画面 + 真实的情绪」去犀利，不用「口号式下判断」去犀利。
6. **公开文案禁用 "Beta"**：绝大多数人看不懂、且显生硬技术腔。公开平台改用「内测 / 第一版 / 早期版本 / 这版免费 / 先找几个真案例」。`Beta` 仅限内部技术讨论或英文产品语境。
7. **事实归属要对、具体优于抽象、英文不缝合（2026-07-24 从失败帖修正）**：① 父亲/家族原话（如"半个桌子"）是**爸爸的理论**，写时归属性不能乱、不能抽象化，要 verbatim（见 §G）。② 她说话永远落地到**具体画面/数字/记忆**（"三百多人就业""十二岁在家族公园"），绝不写 "one era one 命题" 这种中英缝合的抽象句。③ 英文也要短、直白、不 hedge，像 native 思维而非翻译腔，不编造她不会说的 CTA（见 §H、§I）。

## 视频脚本 / 社媒声纹（duo社媒通用声纹）

用户新增的「duo社媒通用声纹」已收入本 skill 同目录 `duo_社媒通用声纹-skill.md`，是**视频脚本的结构标准**；本 skill 是它之上的**最后一道声纹重洗**。

触发：用户要写视频口拨稿 / 脚本 / 分镜文案 / 口播类社媒（多多OS、duoduo wear、本人出镜账号）→ 先读该文件，按它的规则立稿：
- **固定身份**：家庭/商业/旅行/身体/创造之间的**现实实验者**；不是成功导师、不是受害者、不是为反叛而反叛。
- **黄金结构**：扔出真实事件 → 事情变问题 → 保留自我修正 → 只抽**一个**认知 → 回当前动作（不升华）。
- **比例（中文个人视频）**：55% 事件过程 / 25% 原判断与误判 / 15% 一个认知 / 5% 当前动作。
- 中文声纹（§6）/ 英文 WEAR 声纹（§7）/ 六种写法（§8）/ 禁用开头·中间·结尾（§10）/ 12 条质检（§12）全文照办。

流程：写完初稿 → 按本 skill「执行流程」语种分流（中文 qu-ai-wei / 英文 humanize-en）做最后一道声纹重洗 → 用声纹文件 §12 的 12 问二次质检，两项以上「否」整稿重写。

## 执行流程

### 0. 音准基准 = 读 `references/duoduo_voice_dna.md`（多多固定表达 DNA），不要每次去读 journal
**禁止每次发文前再去读 `07_Journals/01 Daily`。** `references/duoduo_voice_dna.md` 已是 **2023–2026/3 共 456 篇 daily journal 逐篇通读后提炼的浓缩声纹（NUWA 式表达 DNA 资产）**——黑海日落、家族公园、父亲「半个桌子」等 verbatim 原声、句法、标点、词汇、情绪规律全在里面。它本身就是"读完日记的总结"，是校准的**唯一音准**，无需重复读原始日记。
- 写任何多多发文前，**只读 `references/duoduo_voice_dna.md`**，照其 verbatim 原句与规则写即可。
- C1 家族主权 → 必读该文件 §G 父亲原声库（已含全部 verbatim + 归属，不另翻日记）。
- 文艺密度 → 照该文件 §A「感官具体的文艺内省」+ §I 反面教材校准，不另读长 journal。
- **唯一例外**：当且仅当用户当次明确说「读我某篇新 journal / 看我最新日记」时，才去读那一篇；否则一律用本档案，绝不主动翻 journal。

### 1. 判定语种，分流
- **中文正文** → 调用 `qu-ai-wei` skill，按它的门检 + 51 条规则执行，但：
  - 冲突时以本 skill 顶层约束为准：**保毛边 > 杀 AI 腔**。qu-ai-wei 的「AI 不敢写测试 / 毛边保护」正好同向，直接利用。
  - 全角标点；**破折号（——）基线≈0，日常语体默认删**（除非是品牌广告/特稿节奏）。
  - 禁用词：赋能 / 打造 / 底层逻辑 / 全方位 / 多维度 / 助力 / 闭环 等。
- **英文正文** → 调用 `humanize-en` skill，但：
  - **em-dash = 0**（<300词零个；>300词最多1个）。
  - 禁 banned words：delve / leverage / robust / comprehensive / streamline / furthermore / moreover / "it is important to note" / tapestry / vibrant / testament / landscape 等。
  - 杀 negation pivot（"not X, it's Y"）——但**多多自己的口号式原话除外**（如 "不躺平也不硬扛" / "not lying flat, not carrying it"，这是她的声音，保留）。
  - 句子长度要有 variance（有 ≤5 词碎片，也有 25+ 词长句）。
  - 附赠 `ai-check-en` 可做自检。

### 2. 不虚构事实（硬约束，与 qu-ai-wei §1 互锁）
- 从 Human3.0 方向包 / 用户已给素材里取事实；**不得发明**数字、事件、人名、原话、金额、地点。
- 毛边可以「挑出来保留」，但**不能为了通过 AI 不敢写测试而编造**细节。

### 3. 平台调性（来自多平台分发矩阵 + Human3.0）
- 小红书 = 主阵地（高知女性、真实、拒绝权威感）。
- 即刻 = 锋利观点；知识星球 = 独家深度；朋友圈 = 单列更私密更犀利（不与公域同稿）。
- X / Threads = 英文观点 + 钩子；Medium / Substack = 英文长文沉淀（GEO）。
- 一稿改写多发，不每平台单独制作；每条只承担**一种动作**（评论 / 私信访谈 / 试穿 / 预售）。

### 4. 自测卡保真度自检（NUWA 式）
改写/生成后，按 `references/duoduo_voice_dna.md` §3 的 4 题自测卡跑一遍：
- 毛边保留 / 犀利够 / 文艺>江湖气 / 未知原声抽检归属。
- 任意一项不达标 → 回炉重洗，不对外发。
- 这是「最后一道声纹重洗」的收口，不可跳过。
