# 视觉理解工具箱 Visual Understanding Toolkit

让任何员工都能复用统一的视觉能力:既能**读懂已有图片**,也能**生成新图片**。

## 何时用
- 需要"读懂"一张或一批图片:提取场景/物体/人物/情绪/推荐用途/叙事功能(vf)等结构化标签
- 需要给图片库做审片、分类、打标、建索引
- 需要生成新图片:文生图、图生图(做封面/素材/概念图)
- 任何员工想复用统一视觉能力,而不各自从头接模型

## 两类能力

### A. 读图分析(vision read)—— 引擎自动选

默认**本地优先**,需要细粒度时**上云**。

**自动选引擎规则:**

| 条件 | 引擎 |
|---|---|
| 常规场景/物体/人物/情绪/推荐用途提取 | 本地 Ollama llava-llama3(照片不外传) |
| 含 vf 时间位置判断(realization 微表情 / hook_face 开场钩子 / end_face 收尾脸 / emotional_peak) | 上云 GPT-5.6 |
| 用户显式要求"最准"或已放开隐私铁律 | 上云 GPT-5.6 |
| evidence 需细粒度补全 | 上云 GPT-5.6 |

**本地读图(核心实现见 `references/ollama_local_read.py`):**
1. 服务: `~/.workbuddy/binaries/ollama/ollama` 已 serve 在 `127.0.0.1:11434`(由 launchd 托管,死掉自动重启)
2. PROMPT 模板:见 `references/read_image_prompt.md`(冒号键值格式,llava 稳定产出)
3. 调用:`/api/generate` 传 base64 图 + prompt
4. 解析:`parse_llava` 做受控词归一化(emotion / recommended_use / vf),**复读守卫**:若 llava 整串复读示例词表则清空防误标
5. 已知坑:合成图会让 llava 退化复读示例词表;真实照片正常。读不了就留空,**绝不虚构**

**上云补全(混合上云,需隐私铁律放开):**
- 用对话模型(GPT-5.6)对本地已读字段做:evidence 细粒度补全、vf 时间位置判定
- 隐私:仅在上云铁律放开时做;照片绝不外传未授权

### B. 生成图片(image gen)—— ImageGen 工具
- 文生图:文字描述 → 图
- 图生图:参考图 + 指令 → 新图
- ⚠️ 每次生成消耗 credits(约 5-10/张),**先告知用户**
- 风格:如用户有品牌设计系统(蓝绿+米、全衬线),生成前先对齐;AI 水印绝不带出

## 铁律(所有员工共用)
1. **不删不改原文件**:读图只产出标签/索引 CSV,绝不移动/删除原图
2. **不编造视觉字段**:读不了就留空(标 `待视觉复核`),绝不虚构场景/物体/情绪
3. **隐私默认本地**:上云需用户明确放开;照片不外传未授权
4. **可逆**:任何改名/整理都走可逆日志(`rename_gen.py` 范式)

## 复用约定
- 本 skill 为 user-level,所有工作区/员工可用
- 读图参考实现可复制 `references/ollama_local_read.py` 到项目用,改 PROMPT 即可
- 生成图走 ImageGen,产出后按各岗设计系统校准
- 大库批量读图参考既有 `~/photo_audit/` 管线(循环编排器 + 看门狗 + 进度快照),可照搬模式
