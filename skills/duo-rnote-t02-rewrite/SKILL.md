# 多多 R 笔记 T02 第一人称重写

> 用途：把 vault `04_KNOWLEDGE WORK/03 Research/Rxx_主题/` 下的笔记，按已批准标准重做成「第一人称「我」+ 多多原话主体 + T02 模板 + Journal 原文归档」的详细学习/研究报告。
> 适用：用户说「重做笔记 / 按 T02 写 / 用我的话 / 一篇一篇来 / 看全部 source 再写」等场景。

## 0｜铁律（不可违背）

1. **先对清需求再动手**：目标 / 成功标准 / 边界 / 交付形式 / 不可逆点。需求不清先追问（grill 标准），不动手。
2. **动笔前通读全部 source 与原文件**：该 R 对应的 `00_SOURCES/Rxx_*/`、旧的 R 笔记、所有被引用的 Journal、对应 topic map（T）。**没读全源不许写，也绝不许冒充已读。**
3. **写作者是多多，不是 AI**：全程第一人称「我」。禁用「你/我对你说」教学腔、禁用「写给小白」式外行开场。
4. **原话作正文主体**：多多的真实项目数据、真实文件名、真实日记原句＝正文骨架；AI 的归纳/提炼只在 `〔AI理解〕`/`〔AI推断〕`/`〔原始事实〕` 块里，且明确标注。
5. **归属标注、不冒充**：谢胜子原话标 `〔谢胜子原话〕`；小红书/外部作者原帖标 `〔作者 XXX〕`；AI 推论标 `〔AI理解〕`/`〔AI推断〕`。
6. **Journal 原文直接归档**：只要 Journal 里出现了且适合归纳，就把那段**逐字复制**进 §08（可改写分类，不改写原文），不用每次问。
7. **诚实留白**：二进制文件（.docx/.ppt 等）本机提取不出正文、或课程/音频未转写的，诚实标 `〔待补〕`，**绝不编造字段值**。
8. **R/T 双层同步**：每写完/重做一篇 R，其对应 topic map（Txx）必须追加 `## 同步记录（YYYY-MM-DD）` 段，并核对来源地图路径是否准确（错标如 gdrive↔百度云 要更正）。

## 1｜T02_学习笔记 模板（§00–§08，必须展开写，不是目录）

- **§00 这是什么**：一句话定义 + 为什么对我重要 + 我的双来源线（自身线 + 外部参考线）+ 本篇读过的真源清单 + 〔待补〕项。
- **§01 一句话核心**：该主题最底层的洞察，一句话。
- **§02 我的原话与原方法**：分小节（2.1 / 2.2 …）展开真实分析——不是列要点，是写**实际的方法论/经验/原话**。每节可标 `〔原始事实〕`/`〔AI理解〕`。
- **§03 立体结构**：骨架 + 比较表 + 文字脑图，把知识织成网。
- **§04 反例与边界**：什么情况下这条不成立 / 常见误用 / 我自己的盲区。
- **§05 现实应用**：马上能做的实验 / audit / 最小行动。
- **§06 术语**：外行词典，谁的话标谁。
- **§07 内容选题**：可回灌其它笔记或做成内容的选题（对接审美系统）。
- **§08 Journal 原文归档**：逐字复制的日记/复盘片段，按时间线，不作改写。

> 长度与深度：用户要求「加长度和深度」，按主题充分展开，不要嫌长。参考已完成的 R13（166行）/R15（123行）/R16（169行）。

## 2｜落盘到 iCloud vault（沙箱拦截必读）

iCloud Obsidian vault 路径：`/Users/Zhuanz/Library/Mobile Documents/iCloud~md~obsidian/Documents/DuoDuo_AI_Workspace/`
Write 工具会被沙箱拦截。**必须用 Bash + `dangerouslyDisableSandbox: true` + heredoc**：

```bash
cat > "/Users/Zhuanz/Library/Mobile Documents/iCloud~md~obsidian/Documents/DuoDuo_AI_Workspace/04_KNOWLED WORK/03 Research/Rxx_主题/00_综合学习笔记.md" <<'RXXEOF'
（markdown 内容，定界符用引号包裹防止 $ / 反引号 展开）
RXXEOF
echo "WRITTEN: $(wc -l < "上面同一个路径") lines"
```

追加同步记录到 T（不要覆盖原文件）：
```bash
cat >> "/Users/Zhuanz/.../02_TOPIC_MAPS/Txx_知识地图.md" <<'TXXEOF'

## 同步记录（YYYY-MM-DD）
- Rxx 已按 T02 重做（第一人称「我」）：全源通读（…）。关联已接 Ryy/Rzz。〔待补〕…。
TXXEOF
```

> sed 更正来源地图里的错误路径标签时，**不要**用 `VAR="..."` 变量赋值 + sed 的写法（权限检查会拒「无法识别命令根」）；路径全部内联写出来。
