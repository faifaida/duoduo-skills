# Layout Recipes

## Recipe 01｜Story to System

适合个人叙事 + 方法论 + 产品发布。

**Part 1**
- Hero title + real scene photo
- Opening story card
- Big quote
- Section 01 external structure
- Section 02 body/emotion
- Section 03 turning point

**Part 2**
- New tool/system
- Counter-illusion quote
- 3 experiment cards
- Big mission question
- Beta/offer card
- Sign-off

## Recipe 02｜Project Field Notes

适合文旅、青旅、品牌、空间案例。

- Project hero
- Project facts strip
- Problem / role / action
- Before-after evidence
- Unresolved questions
- Learning cards
- Collaboration CTA

## Recipe 03｜Travel Essay

- Location stamp
- Main travel image
- Scene narration
- Person/object cards
- Map route
- What changed / what remains
- Next destination / question

## Recipe 04｜Product Experiment

- Product origin
- Body/problem insight
- Sample photo grid
- Test data
- Current flaws
- What is changing
- Tester application CTA

## Recipe 05｜Framework Article

- Thesis hero
- Problem landscape
- 3–5 numbered principles
- Diagram/axis
- Personal example
- Boundary and counterexample
- Small experiment CTA
