# 通道 D · 云盘 / 本地归档重分类 + 知识提炼

适用：Google Drive、OneDrive、企业网盘、本地课程笔记堆、Notability 笔记等。

## D0. 核心原则（多多定的模式，2026-08-01 确立）

- **个人文件 → 归进已有 iCloud 文件夹**（`Career/简历`、`以前照片`、`工作` 等），不新建平行体系。
- **知识类 → `04_KNOWLEDGE WORK/00_SOURCES/<科目>/`（源）+ `02_TOPIC_MAPS/T10_*.md`（提炼）**。
- **不碰现有主题文件夹**（`03 Research` 下的 ESG / Personal Finance 等已整理内容）——新内容进 00_SOURCES 或新建地图。
- 🚫 **严禁整盘平铺进一个新建的「XX_归档」文件夹**。多多明确反感，踩过一次了。

## D1. 前置：rclone 通路（Google Drive 场景）

- 容器内 localhost 与 Mac 浏览器**隔离** → OAuth 回调必须让多多在 **Mac 原生 Terminal** 跑 `rclone config`（选 `drive`、scope `1`、浏览器授权）。容器里只用现成 token（`~/.config/rclone/rclone.conf`）。
- 外网走本地代理 `HTTPS_PROXY=http://127.0.0.1:7897`（容器直连被中间盒 TLS 拦截）。
- 装 rclone：GitHub Releases 下 `osx-arm64` zip（走代理），SHA256 校验，装 `~/bin` 写 PATH。

## D2. 流程

1. **拉取**
   ```bash
   rclone copy gdrive: <本地临时区> \
     --drive-export-formats docx,xlsx,pptx,pdf \
     --fast-list --transfers 2 --checkers 4 --retries 5
   ```
   分文件夹跑，避开代理列举截断；增量可反复补。

2. **验证拉取**（**别信 `Transferred 100%`**）
   `rclone ls gdrive: | wc -l` 比对 `find <dst> -type f | wc -l`；用 `comm` 比路径差集，定性区分「同名重复折叠」vs「真漏」。

3. **解剖 Notability `.note`**
   本质是 zip 包：
   - `Session.plist` — NSKeyedArchiver 二进制，**typed text 很稀疏**（首次 plistlib 解析可能只出 UIImage/NSString 类引用）。
   - `PDFs/*.pdf` — **真正的知识主体**在这里。
   - 还有手写矢量、录音、图片。手写多 → 数字文本就少。

4. **文本抽取**
   venv 装 `pdfminer.six` + `python-docx` + `python-pptx`（pip 走代理）。脚本遍历 `.note/.pdf/.docx/.pptx`：
   - 每篇原文 → `/tmp/drive_corpus/<subject>/<safe_rel>.txt`
   - manifest → `/tmp/drive_manifest.csv`（relpath / ext / subject / char_count / preview）

5. **分类 move**（用 move 不用 copy —— 源在云端，本地临时区不留残骸）
   - 简历 → `Career/简历`
   - 照片 / 视频 → `以前照片`
   - 其余 → `00_SOURCES/<科目>/`
   - 同名文件：size 相同 → 丢弃（防重复）；不同 → 加前缀区分。
   - ⚠️ **媒体文件没文本、不在 manifest 里**，容易被当 leftover 扫进课业桶 —— 分类前先按扩展名单独挑出媒体。

6. **知识提炼**
   生成每科 digest（大文档/教材只取前 ~1500 字预览，小文件全文 ~4000 字）→ 读 digest → 写
   `02_TOPIC_MAPS/T10_<主题>知识地图.md`（关键框架 / 公式 / 章节结构 / 与其他主题的关联）。

7. **源索引**
   `00_SOURCES/<总索引>.md` 列全部对象及落点，备注特殊情况（待 OCR、已取到、真漏等）。

8. **清理**
   验证归位无误、临时归档 0 文件残留 → 再删。**源云盘不动。**

9. **回报**
   写 `03_资料员/回报_YYYYMMDD.md`（当天一份，追加）；在 `iCloud总档案索引.md` 补审计备注。

## D3. 关键坑

| 坑 | 处理 |
|---|---|
| 代理列举 CJK 文件夹会截断/损坏 | 分文件夹 copy + `--fast-list` |
| OAuth 回调容器隔离 | Mac 原生 Terminal 授权 |
| 手写笔记数字文本极少 | 源归档标「待 OCR」，**别谎报「已解析」** |
| 单个 .note 教材极大（Mankiw 1.8M / Larson 1.9M / 商法 8.4M 字符） | digest 只预览，地图靠章节结构 + 大纲提炼 |
| 真漏文件（罕见） | 只能 Mac Terminal 补取，把命令附进索引，**别假称缺失** |
| 媒体文件被扫进知识桶 | 分类前按扩展名先挑走照片/视频 |

## D5. iCloud 大盘整理原则（多多 2026-07-30 定）

- 真实项目**不搬大文件**；先不做跨位置移动，只做云盘**内部**规整（建索引 / 去明显重复 / 标注待归类）。
- **重复不删只标记** → 移 `⚠️_疑似重复_待确认/`，保留。
- **最新编辑 = 重要**（索引里 🔥 标当年内编辑过的）。
- 动个人文件或删除前**必须多多授权**；删也只进废纸篓，不永久删。
- **应用数据夹（如 Workbuddy）不纳入去重**（「路径最短优先」会误伤，踩过）。
- 不碰：Desktop / Documents（macOS 同步个人夹高风险）、产品经理产品（胜子 / 曲曲系列）。

## D6. 百度网盘 MCP 通道（2026-08 实战，区别于 rclone 本地通道）

百度网盘走 **百度网盘 MCP**（`mcp__baidu-netdisk__*`），**不下载、保持云端原位**，在云盘内部规整 + 抽 topic map + 归位 research。适用「个人文件在百度云、要重新分类但不落地本地」的场景。

### D6.1 工作流（双层归位）
1. `file_list` 探明顶层与嵌套结构（**注意分页陷阱，见 D6.3**）。
2. 用 `file_move`（ondup:newcopy）在云盘内重新分类、抽空壳、建基础分类夹 + 设备备份保持原样。
3. 深度去重：`file_list` 逐对列原夹 / 副本夹，按 `文件名+size+md5` 判纯重复 / 独有 / 异版（见 D6.3）。
4. 写 **topic map** → `02_TOPIC_MAPS/Txx_*.md`（`type: topic-map`）。
5. 把消化内容**归位 research**（补已有 R / 新建 R / 纯消费只索引）——见 SKILL.md 二-B。
6. 可逆删除：删 = `file_move` 到 `/_recycle_YYYYMMDD` 暂存夹；真删需网页端。

### D6.2 Vault 定位（写回 topic map / research 时用）
- **Vault 在 iCloud Obsidian 同步容器，不是 iCloud Drive**：`/Users/Zhuanz/Library/Mobile Documents/iCloud~md~obsidian/Documents/DuoDuo_AI_Workspace/`。
- iCloud 遍历极慢（Glob 超时、find 爬数分钟无果）→ 用 **Spotlight `mdfind`** 秒级定位：
  - `mdfind -name "T04_每周复盘"` 找模板
  - `mdfind "kMDItemFSName == '.obsidian'"` 找 vault 根
- 写文件用 `cat > ... <<'EOF'` + `dangerouslyDisableSandbox: true`（沙箱写不进 iCloud）。
- 错位 / 不要的 vault 笔记：移入 `DuoDuo_AI_Workspace/.trash/`（可逆），不要直接 rm。

### D6.3 百度网盘 MCP 关键坑（实测，复用）
| 坑 | 处理 |
|---|---|
| **分页陷阱**：`file_list`（根或子夹）恰满 10 条/页，连子文件夹也只回 10 条 | 返回正好 10 条 → 必翻 `page+1` 直到不足 10 条；比对「独有文件」前两侧都翻满，否则误判（本项目 3 次撞出 `(1)` 副本） |
| **可逆删除**：MCP 无 delete 原语 | 删除 = `file_move` 到 `/_recycle_YYYYMMDD` 暂存夹（ondup:newcopy），真删再网页端清空 |
| **深度去重 md5 比对** | 逐对 list 原夹/副本夹，按 `文件名+大小+md5` 判纯重复/独有/异版；**异版（md5 不同）两份共存不盲删**，纯重复留暂存 |
| **路径编码坑**：`file_list` 用 `dir` 且中文需 URL-encode（含斜杠）；`file_move`/`file_rename` 用纯 UTF-8 | 编码会 `-7 找不到源`；`make_dir` 传纯路径防怪名 |
| **编码误打**：`%2F` 勿误打成 `%3F` | 问号 → `1002` 参数错 |
| 同名异版（md5 不同）两份共存 | 在 topic map 列 md5 对照表，待多多定夺后由她决定去留 |
