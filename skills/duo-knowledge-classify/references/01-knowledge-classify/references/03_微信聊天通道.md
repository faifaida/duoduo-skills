# 通道 C · 微信聊天记录 → Obsidian Markdown

## C0. 定位

macOS 微信没有内置「导出到文件」，数据在沙盒容器里且加密。所以导出是**限定范围、需明确授权**的动作，不是批量流水线。

## C1. 铁律：先确认范围，再动手

1. **绝不全量导出。** 每次由多多指定要导哪些会话（群 / 人）。
2. 能列出候选就先列给她挑，**范围没确认前不碰数据**。
3. 抽取时**只碰她批准的那几个会话**，其余一律不读。

## C2. 流程

1. **确认范围** — 问多多导哪些聊天，等她回。
2. **定位数据** — 沙盒路径 `~/Library/Containers/com.tencent.xinWeChat/Data/...`。聊天 DB 加密，取可读历史需要 session key 或受支持的导出方式。**方法不确定就停下来问，别猜着乱试。**
3. **抽取** — 仅批准范围内的会话。
4. **转 Markdown** — frontmatter 带 `date` / `peer` / `message_count`，写进多多指定的 Obsidian 目录，按日期可检索。
5. **回一份清单** — 导了哪些会话、各多少条、落在哪。

## C3. 安全

- 这条通道会碰**私人消息内容**：产物一律留在 Vault 内，禁止任何对外动作。
- 归类时**脱敏**（人名/手机号/地址等按需处理），摘要要能一眼扫完。
- 超出批准范围的会话，一条都不导。

## C4. 依赖多多先给包

若走「多多本地导出包」路线：**没拿到导出包前不空转**，先去收尾 email / 其他通道的活，别干等。

- `wechat-article-pro` — 公众号长文撰写发布，同上。

## C6. 动作节点（多多视角）

1. 你指定导哪些聊天（群/人），我不全量导。
2. 我从本机微信数据里抽取指定会话。
3. 转成 Markdown 落进 Obsidian 指定目录，带日期，可搜。
4. 导前跟你确认范围，导后给你清单（导了哪些、多少条、落在哪）。
