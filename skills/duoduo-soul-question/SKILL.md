# duoduo-soul-question（每日灵魂拷问）

多多「研究学习官」角色的每日仪式。目的不是完成打卡，也不是要求她立刻解决人生问题，而是：

> 让她带着一个真正与当下有关的问题进入这一天，在生活、工作、身体和选择中慢慢观察答案。

## 何时触发
- **自动**：每天 **13:00**（对应自动化，本 skill 的默认运行时间）。
- **手动**：多多说「灵魂问题 / 今日问题 / 灵魂拷问 / 每日一问」等。

## ⚠️ 铁律（不可违反）
1. **每天只问一个问题**。不同时给第二个、不给今日任务、不给鼓励鸡汤、不给回答示例、不做背景分析——除非多多明确要求。
2. **问题必须来自多多当下真实线索**，不是随机抽取的通用心灵问题。生成前必须读近期日记 + 前一天回答。
3. **不重复最近 7 天问过的核心主题**。生成前先读本月档案，避开近期问过的问题与主题。
4. **不暗示"正确答案"、不评价多多、不制造焦虑或任务感、不要求写长日记。**
5. **不把提问变成建议或说教。** 问题就是问题，留白让她自己观察。
6. 多多能量低/疲惫/崩溃时，问题更温和、更具体，优先帮她识别生命力和身体需要，**不继续深挖创伤**；不连续提沉重/治疗性问题。
7. **只有连续出现 3 次以上的模式**才可在周报/月报里标注为"可能重复出现的主题"，且明确这只是观察、不是定论。绝不因单次回答给多多贴标签。

## 每日执行流程

### 第 1 步：读线索（生成问题前必做）
按需读取，判断当下最有生命力、最可能影响她今天判断的主题：
- `07_Journals/01 Daily/<YYYY>/`（2026-08-03 起按年归档，遍历对应年份子目录，如读最近几天则读 `01 Daily/2026/`）—— 最近 2–3 天日记（最近发生的事、反复情绪、身体/能量/睡眠信号、未完成任务、四方向进展）。
- `07_Journals/04 Personal reflections/Soul Questions/YYYY-MM_Daily Soul Questions.md` —— 本月灵魂问题档案（前一天回答 + 近 7 天问过的主题，用于避重）。
- `02_CONTEXT/08 多多生活系统.md`（若存在）—— Life OS / 月相节奏，作为节奏依据。
- 研究学习官近期研究结论（`08_研究学习官/` 或 `04_KNOWLEDGE WORK/`）—— 可把研究结论转化为与她有关的问题（但问题不得变成知识测验）。
- 多多个人上下文：个人公司/收入/理财实验、自由/旅行/冲浪/地点选择、家庭资源与独立能力、创作/审美/学习、人际/依恋/被理解、反复矛盾。

### 第 2 步：主题轮换（不机械平均）
在以下主题间自然轮换，优先当下最有生命力的那个：
1. 身体与能量　2. 自由与边界　3. 金钱与安全感　4. 个人公司与能力建设　5. 创造力与生命力
6. 家庭、资源与自主性　7. 关系与被理解　8. 旅行、冲浪与理想生活　9. 选择、代价与责任　10. 最近学到的新认知

### 第 3 步：出题标准（生成的问题必须满足）
- 三分钟内能回答；一句话即可开始回答；但值得当天继续观察。
- 具体（来自一个真实场景/选择/情绪/身体信号/行为），不抽象口号。
- 开放，但不宽泛到无从回答。
- 不同时问两个以上问题。

**⚠️ 可懂性标准（2026-07-27 多多反馈后新增，参考 GitHub hs3180/disclaude 的 daily-soul-question 写法）**：
- **先给背景，再给问题**。问题前用 1–2 句大白话点出「我从哪条线索看到了什么」，让她一眼知道问题指的是哪件具体的事。这不算"背景分析"，是问题的一部分（铁律 1 禁止的是长篇解读和建议）。
- **问题必须能被"秒懂"**：读一遍就明白在问什么。禁止压缩抽象的文学化问法（反例：「有没有哪一件你其实是想自己留下的？」——"留下"指什么没人知道）。宁可句子长一点、直白一点，也不要漂亮但难懂。
- **自检**：写完后自问"如果她只读一遍，能不能立刻开始回答？"若需要先猜词义，重写。
- 指代要落地：不说"这件事/那个角色"，直接点名是哪个项目、哪笔钱、哪次对话。

**好问题示例**（仅作标准参考，不要机械复制）：
- 今天哪一件事即使没人看见，你仍然愿意做？
- 你最近说"我没办法"的事情里，哪一件其实是"我不愿意付这个代价"？
- 你现在想统一管理自己的钱，是为了获得更多收益，还是为了减少失控感？
- 你正在建立的个人公司，今天具体替你争取了哪一种自由？
- 最近哪一个"应该做"，正在悄悄吞掉你的"想做"？

**不合格问题（禁止）**：你今天感觉怎么样？／你今天最重要的事是什么？／你的人生目标是什么？／今天你感恩什么？／今天有什么计划？／你为什么不努力一点？——以及一切空泛、评价性、任务性、鸡汤式问法。

### 第 4 步：输出（当天早上/13:00 只输出这个）
```markdown
## 今日问题

（1–2 句大白话背景：我从哪条线索看到了什么。让问题落地，不是分析。）

> 一个具体的、读一遍就懂的问题
```
除上面的 1–2 句背景外，不附长篇解释、回答示例、建议、任务、第二个问题或鸡汤。让问题本身留出空间。

同时把「今日已出题」这条记录写入本月档案（问题原文 + 日期），回答栏留空待填。

### 第 5 步：多多回答之后
1. 先准确理解回答。
2. 用 1–3 句指出其中最值得注意的部分（不立即变任务清单、不每次都做心理分析）。
3. 只有多多明确表示想深入时，才继续追问。
4. 把回答与观察补进本月档案。

## 档案与格式

**保存路径**：`07_Journals/04 Personal reflections/Soul Questions/`
**文件名**：`YYYY-MM_Daily Soul Questions.md`（按月一个文件，追加，不覆盖）

**每日记录格式**：
```markdown
## YYYY-MM-DD

### 今日问题

> 问题

### 多多的回答

回答原文。（未回答则留「（待回答）」）

### 观察

只记录 1–3 句基于回答的观察，不下诊断，不贴标签。

### 可能关联

- 当前项目：
- 身体与能量：
- 反复主题：
- 后续是否值得重访：
```

## 与研究任务的连接（可选）
前一天完成了研究时，可把研究结论转化为与多多有关的问题。例：
- 研究「AI 辅助个人理财」→ 不问"你今天准备如何理财?"，可问"你想把所有账户放一个地方，是为了更方便，还是因为你不愿再面对自己不知道钱在哪里?"
- 研究「个人公司产品设计」→ "你今天想卖的这个产品，解决的是别人的真实问题，还是你希望别人认同的自我形象?"
问题可受研究启发，但**不得成为知识测验**。

## 完成后
- 出题当天：确认本月档案已追加当天问题记录（回答留空）。
- 按记忆规则，向 `08_研究学习官/.workbuddy/memory/YYYY-MM-DD.md` 追加一行「今日灵魂问题已出：<问题>」。
